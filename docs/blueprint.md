# **App Name**: EASTCHAIN

## Core Features:

- Identity Mapping & Wallet Generator: Uses a custom hashing algorithm to transform Telegram IDs into unique cryptographic wallet addresses stored within the ledger infrastructure.
- Celestial Node Map: An interactive 3D WebGL visualization of the Earth and Galaxy where user nodes orbit and pulse based on real-time activity.
- Network Performance Reasoning Tool: A tool that utilizes AI to analyze network stability and connection metrics across the community to dynamically nominate the top 10 validators.
- Consensus Proof of Internet Engine: Backend engine that verifies connectivity and grants a 2x hashrate multiplier for active validator nodes.
- Global Hybrid Ledger: A high-concurrency database structure serving as a local ledger for tracking mining sessions, balances, and real-time transaction history.
- Live Block Explorer: An integrated explorer to inspect the ledger, enabling full transparency for every transaction across the node network.
- Unified Navigational Dashboard: Fixed bottom navigation system providing quick access to Mining, Wallet, Swap, Explorer, and Profile views.

## Style Guidelines:

- Primary color is a Deep Galactic Violet (#7C3AED), reflecting the vastness of the digital universe.
- Background color is a desaturated, very dark Space Ink (#0E0C12), maintaining consistency with the dark galaxy theme.
- Accent color is a vibrant Sky Indigo (#3B82F6), chosen to be analogous to the primary color to represent connectivity paths.
- Header font is 'Space Grotesk' for a technological and futuristic aesthetic. Body font is 'Inter' to ensure maximum legibility for financial data.
- Code font: 'Source Code Pro' is used for wallet addresses and block hashes to emphasize transparency and precision.
- Minimalist centered-content layout featuring a prominent 3D planet, with a persistent ergonomic bottom tab bar optimized for Telegram's mobile view.
- Slow, smooth orbital rotations for the Earth visualization and subtle glowing pulses on active node markers.
